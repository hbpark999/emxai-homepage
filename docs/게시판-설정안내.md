# 교육 게시판 설정 안내

교육 중 강사가 **Notion에 글을 쓰면 홈페이지 게시판에 실시간으로 표시**되는 구조입니다.
수강생은 로그인 없이 주소만으로 열람합니다.

```
[대표님] Notion 앱(폰/PC)에 작성
              ↓
[홈페이지] /api/board 가 Notion 조회 (5초 캐시)
              ↓
[수강생] /education/board 화면이 5초마다 자동 갱신
```

추가 비용은 없습니다. Notion 무료 플랜에 공개 API가 포함되어 있습니다.

---

## 1단계 — Notion 데이터베이스 만들기

Notion에서 새 페이지를 만들고 **표(Table) 데이터베이스**를 추가합니다.
페이지 이름은 자유롭게 정하세요. (예: `EMxAI 교육 게시판`)

아래 4개 속성을 만듭니다.

| 속성 이름 | 유형 | 용도 |
|---|---|---|
| `제목` | 제목(Title) | 글 제목 — 기본으로 있는 속성 이름만 바꾸면 됩니다 |
| `내용` | 텍스트(Text) | 본문. 링크·코드·공지를 적습니다 |
| `공개` | 체크박스(Checkbox) | **체크된 글만** 홈페이지에 표시됩니다 |
| `과정` | 선택(Select) | 교육 과정 구분. 2개 이상이면 게시판에 필터 버튼이 생깁니다 |

> 속성 이름은 유형만 맞으면 영문(`Name`, `Content`, `Published`, `Course`)이어도 동작합니다.
> `공개` 속성을 만들지 않으면 모든 글이 표시됩니다.

**작성일은 따로 만들지 않아도 됩니다.** Notion이 기록하는 생성 시각을 자동으로 사용합니다.

---

## 2단계 — 통합(Integration) 만들고 토큰 받기

1. Notion 좌측 하단 **설정** → **연결(Connections)** → **직접 연결 개발하기**
   (또는 브라우저에서 `https://www.notion.so/my-integrations` 접속)
2. **+ 새 연결** 클릭
3. 이름 입력 (예: `EMxAI Homepage`), 워크스페이스 선택 → 저장
4. 만들어진 연결의 **•••** 메뉴에서 **내부 통합 시크릿**을 복사

`ntn_` 으로 시작하는 긴 문자열입니다.

> **이 값은 비밀번호와 같습니다.** 메신저나 메일로 보내지 마시고, 소스코드에 직접 적지 마세요.

---

## 3단계 — 데이터베이스에 통합 연결

**이 단계를 빠뜨리면 조회가 실패합니다.**

1. 1단계에서 만든 게시판 페이지를 엽니다
2. 우측 상단 **•••** 클릭
3. **연결(Connections)** → **연결 추가**
4. 2단계에서 만든 통합(`EMxAI Homepage`) 선택

---

## 4단계 — 데이터베이스 ID 찾기

게시판 페이지를 브라우저에서 열고 주소를 봅니다.

```
https://www.notion.so/작업공간/1a2b3c4d5e6f7890abcdef1234567890?v=...
                              └───────────── 이 32자리가 ID ─────────────┘
```

`?v=` **앞의 32자리**가 데이터베이스 ID입니다. 하이픈은 있어도 없어도 됩니다.

> 페이지 안에 표를 넣은 경우(인라인 데이터베이스)는 표 우측 상단 **•••** → **전체 페이지로 열기**를 한 뒤 주소를 확인하세요.

---

## 5단계 — 로컬 환경변수 설정

프로젝트 루트(`emxai-homepage` 폴더)에 **`.env.local`** 파일을 만들고 아래를 넣습니다.

```
NOTION_TOKEN=ntn_여기에_2단계에서_복사한_시크릿
NOTION_BOARD_DB_ID=여기에_4단계에서_찾은_32자리_ID
```

`.env.local`은 `.gitignore`에 포함되어 있어 Git에 올라가지 않습니다.

**확인**

```bash
npm run dev
```

브라우저에서 `http://localhost:3000/education/board` 접속
→ Notion에 넣은 글이 보이면 성공입니다.

---

## 6단계 — Vercel 환경변수 등록

로컬에서 확인됐으면 배포 환경에도 같은 값을 넣습니다.

1. Vercel 대시보드 → 해당 프로젝트 → **Settings** → **Environment Variables**
2. 아래 두 개를 추가 (Production / Preview / Development 모두 체크)

| Name | Value |
|---|---|
| `NOTION_TOKEN` | `ntn_...` |
| `NOTION_BOARD_DB_ID` | 32자리 ID |

3. **Save**
4. **Deployments** 탭 → 최신 배포의 **•••** → **Redeploy**

> 환경변수는 빌드 시점에 주입되므로, 저장만 하고 재배포하지 않으면 반영되지 않습니다.

## 교육 중 사용법

**글 올리기 (대표님)**

1. 폰이나 PC에서 Notion 게시판 열기
2. 새 행 추가 → `제목` 입력 → `내용`에 링크나 코드 붙여넣기
3. **`공개` 체크박스를 켭니다** ← 이걸 켜야 화면에 나타납니다

최대 5초 안에 수강생 화면에 표시됩니다.

**수강생에게 전달할 주소**

```
https://www.emxai.net/education/board
```

Education 페이지 상단의 **"교육 게시판 열기"** 버튼으로도 들어갈 수 있습니다.

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| "게시판이 아직 설정되지 않았습니다" | 환경변수 미설정 또는 재배포 안 함 |
| "Notion 조회 실패 (404)" | **3단계 통합 연결 누락** 또는 DB ID 오류 |
| "Notion 조회 실패 (401)" | 토큰이 잘못됨 |
| 글이 안 보임 | `공개` 체크박스가 꺼져 있음 |
