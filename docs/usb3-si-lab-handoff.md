# USB3 SI Lab 홈페이지 연결 안내

작성일: 2026-09-16. 갱신일: 2026-10-03.
목적: 공개 홈페이지와 비공개 실습 서비스의 역할 구분.
기능·검증 상태 기준: private 저장소 `hbpark999/usb3-si-lab`의 commit `a82ae4e97ee0f3ebfb29953f879bbdb8344ab5fa`, README 및 `docs/status.md`.

USB3 SI Lab 구현은 별도 private 저장소에서 관리합니다.
이 공개 저장소에 계산 코드, Docker 이미지, 비밀값, 학생 데이터, 업로드 원본 또는 해석 결과를 복사하지 않습니다.

홈페이지에는 소개와 배포 검증 후 실습 실행 링크만 둡니다.
Cloud Run GUI 및 MCP는 독립적으로 배포할 계획이며, 실제 배포는 아직 완료되지 않았습니다.
GUI는 로그인 없이 사용하고 서명된 브라우저 쿠키로 파일과 결과를 분리하는 로컬 구현입니다.
같은 브라우저에서 결과를 재사용하며 익명 GUI 결과를 계정 기반 MCP와 자동 공유하지 않습니다.
원격 MCP 인증은 별도이며 수강생에게 GitHub 접근 권한이나 API 키를 요구하지 않습니다.

## 현재 구현된 기능 범위

- Touchstone 입력, 포트 매핑 확인, 4/8포트 채널 구성, CMF·AC 커패시터 연결, microstrip·대칭 stripline 교육용 준정적 모델.
- 혼합모드 S-parameter와 차동 TDR, s4p·메타데이터 및 JSON/PNG/PDF 보고서 출력.
- Gen1/Gen2 PRBS Eye, 교육용 CTLE/DFE 전후 비교, 선형 대체 엔진 및 별도 환경의 PyBERT 연계.
- IBIS 부분 파서·모델/곡선/패키지 Viewer와 typical TX 조건의 근사 연결. 정식 ibischk, AMI 및 완전한 비선형 버퍼 해석은 미구현.
- 파형 기반 지터 분석(TIE p-p/RMS, 반복 PRBS 기반 DDJ·DCD) 및 PyBERT 내부 지터 추정 표시. 유한 기록의 관측값이며 통계적 BER 꼬리나 RJ/TJ 외삽을 제공하지 않습니다.
- USB 규격 참고 프로파일(compliance reference profiles)과 조건·참고값 비교. 정식 적합성 시험이 아니며 USB 규격 적합성은 `NOT_EVALUATED`입니다. RX JTOL 및 케이블·커넥터 인증 시험은 미지원입니다.
- 업로드 s4p 커넥터를 단일 차동쌍 채널의 입력/출력에 조합(connector assembly). 기준면과 기존 채널에 해당 접속부가 미포함임을 확인하고 중복 삽입을 차단합니다. 인접 레인 누화나 커넥터 인증을 대체하지 않습니다.
- GUI와 MCP는 동일 계산 코어를 사용합니다. LangGraph/운영자 Claude API Agent는 아직 미구현입니다.

## 검증 상태와 미완료 배포

`docs/status.md`에는 pytest 59개 검증 통과가 기록되어 있습니다
(2026-09-17: 전체 실행에서 58개 통과 후 신규 테스트의 예외 기대값을 수정하고 해당 1개를 재실행하여 통과).
이는 기존 로컬 검증 기록이며 이번 홈페이지 문서 갱신에서 private 서비스 테스트를 재실행한 결과가 아닙니다.
로컬 브라우저 격리·만료, GUI HTTP 대기열의 예제/TDR 해석과 JSON 다운로드 등은 확인되었습니다.

다음 항목은 아직 완료되지 않았습니다.

- 실제 Google OAuth, GCS, Redis 및 Cloud Run 배포 통합 시험.
- 컨테이너 이미지 빌드·배포와 공개 서비스 URL 발급.
- 실제 24명 동시 접속 및 수강생 본인 Claude 계정 연결 시험. 24명 부하 시험은 사용자 요청으로 수행하지 않았습니다.
- 측정·제조사 데이터 교차 검증. 유한 대역 인과성은 WARN/미확인입니다.
- PyBERT Linux 컨테이너·클라우드 실행 검증. 기본 이미지는 선형 대체 엔진을 사용합니다.

교육용 준정적 모델은 정밀 EM 해석을 대체하지 않습니다.
Eye 관측 BER=0을 규정 BER에서의 통과로 해석하지 않으며, 규격 참고 비교로 PASS/FAIL을 주장하지 않습니다.
7일 결과 보관·소유권 검사는 로컬 구현 상태이며 운영 GCS lifecycle 설정과 클라우드 접근 격리 검증이 필요합니다.

## 배포 후 홈페이지에 반영할 항목

- 기존 솔루션 카드 옆에 USB3 SI Lab 소개를 추가합니다.
- 소개: "USB 3.x 채널의 S-parameter·혼합모드·TDR, Eye/IBIS·지터 및 커넥터 조합을 비교하고 규격 참고 조건을 확인하는 교육용 실습 도구".
- 실제 배포·접근 격리 검증을 마친 HTTPS GUI 주소를 새 창으로 연결합니다.
- 검증된 원격 MCP 인증·연결 안내를 함께 표시합니다.

실제 Cloud Run 배포와 운영 URL 발급이 미완료이므로 현재 홈페이지 실행 링크를 추가하지 않습니다.
홈페이지와 실습 서비스 사이에 iframe 또는 API 프록시는 필요하지 않습니다.
소스 저장소의 private 설정과 별개로 운영 서비스의 브라우저별 데이터 접근 검증을 유지합니다.
