# USB3 SI Lab 홈페이지 연결 안내

작성일: 2026-09-16. 목적: 공개 홈페이지와 비공개 실습 서비스의 역할 구분.

USB3 SI Lab 구현은 별도 private 저장소에서 관리합니다.
이 공개 저장소에 계산 코드, Docker 이미지, 업로드 또는 해석 결과를 복사하지 않습니다.

홈페이지에는 소개와 실습 실행 링크만 둡니다. Cloud Run GUI 및 MCP는 독립적으로 배포하며,
수강생은 등록한 Google 계정으로 인증합니다. GitHub 접근 권한이나 학생 API 키는 필요 없습니다.

## 배포 후 홈페이지에 반영할 항목

- 기존 솔루션 카드 옆에 USB3 SI Lab 소개를 추가합니다.
- 소개: "USB 3.x 채널의 S-parameter·혼합모드·TDR을 비교하는 교육용 실습 도구".
- 검증된 HTTPS GUI 주소를 새 창으로 연결합니다.
- 운영자가 제공하는 MCP 연결 안내를 함께 표시합니다.

실제 Cloud Run 배포와 URL 발급은 아직 진행하지 않았으므로 현재는 실행 링크를 게시하지 않습니다.
홈페이지와 실습 서비스 사이에 iframe 또는 API 프록시는 필요하지 않습니다.
소스 저장소의 private 설정과 별개로 운영 서비스의 로그인·권한 검증을 유지합니다.
