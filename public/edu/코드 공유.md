## 예시 1 — Z0 계산
```python
# 특성 임피던스 Z0 간단 계산 예시
import math

def z0_microstrip(w, h, er):
    # w: 선폭, h: 유전체 두께, er: 유전율
    eeff = (er + 1) / 2 + (er - 1) / 2 * (1 / math.sqrt(1 + 12 * h / w))
    return 87 / math.sqrt(eeff + 1.41) * math.log(5.98 * h / (0.8 * w + 0.1))

print(z0_microstrip(0.2, 0.1, 4.4))
```
